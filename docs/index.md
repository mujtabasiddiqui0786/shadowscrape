# shadowscrape

A Python web scraping framework: fast HTTP with browser TLS impersonation, stealth browsers, adaptive parsing and concurrent crawling behind one `Response` object.

- **Fetch:** HTTP fetchers with TLS/JA3/HTTP2 impersonation, sessions, retries, proxy rotation, and stealth browsers with Cloudflare Turnstile handling.
- **Parse:** CSS, XPath, text and regex search, similar-element matching, adaptive selectors, clean Markdown.
- **Crawl:** concurrent spiders, AutoThrottle, pause/resume, streaming, JSON/JSONL/CSV/XML export, templates.
- **Agents and terminal:** CLI, interactive shell, MCP server, Agent Skill.

Start with the [quickstart](quickstart.md). Read [Stealth](stealth.md) for what is and isn't proven.
