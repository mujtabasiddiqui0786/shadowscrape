# Examples

| File | Shows | Network |
|---|---|---|
| `01_http_basic.py` | HTTP fetch with TLS impersonation, sessions | yes |
| `02_parse_and_adapt.py` | parsing, similar elements, Markdown, adaptive selectors | no |
| `03_spider_export.py` | a spider with AutoThrottle, pause/resume and exports | yes |
| `04_stealth_browser.py` | stealth browser, JS rendering, XHR capture | yes, needs chromium |

The network examples use quotes.toscrape.com, a site built for scraping practice. Point them at your own targets only where you have permission, and keep the request rate low.
