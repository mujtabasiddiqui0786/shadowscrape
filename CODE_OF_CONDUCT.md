# Code of conduct

We want this to be a welcoming project.

- Be respectful and assume good faith. Disagree about the work, not the person.
- No harassment, discrimination, or personal attacks.
- Keep discussion on topic, and keep reports of bugs or benchmark results factual.
- Maintainers may edit, hide or remove comments and contributions that break these rules.

To report a problem, open a private security advisory on the repository or contact the maintainer through their GitHub profile.
